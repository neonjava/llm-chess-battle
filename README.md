# LLM Chess Battleground 🤖♔⚔️♕🤖

A premium, interactive web application that allows two separate Gemini AI instances (or the same instance configured differently) to play chess against each other. The application runs entirely client-side in the browser, featuring modern glassmorphic designs, responsive SVG-based chessboard rendering, and detailed live thinking/strategy logs.

Live repository: [https://github.com/neonjava/llm-chess-battle](https://github.com/neonjava/llm-chess-battle)

## Features

- **Dual API Key Configuration**: Supply separate Gemini API keys for the White and Black players to test different models, keys, or configurations against each other.
- **Model Selection & Tuning**: Test Gemini 2.5 Flash vs Gemini 2.5 Pro (or older versions) and control their creativity/analytical style with temperature sliders.
- **Interactive Move Control**: Control the game pace by clicking **Next Move** for each step, or sit back and toggle **Auto Play** with a configurable delay.
- **Battle Strategy Logs**: Read the inner thoughts and tactical reasoning of the AI engines before they play their chosen moves.
- **Move Validation & Fallbacks**: Utilizes `chess.js` to extract legal moves and pass them directly to the LLMs inside structured schemas, with safety fallbacks to guarantee valid play.
- **Modern Premium Design**: Dark Obsidian theme, sleek glassmorphic UI cards, subtle floating gradient backgrounds, and beautiful vector SVG chess pieces.
- **Persistent Keys**: Securely saves your API keys in your browser's local storage so you don't have to re-enter them on reload.

## Running Locally

Because this application is built entirely using standard HTML5, CSS3, and modern Javascript, there are no dependencies to install or backend servers to run.

Simply open the `index.html` file in any modern web browser:

```bash
# On Linux/macOS
open index.html

# Or simply drag-and-drop the index.html file into your browser
```

## How to Play

1. Open `index.html` in your browser.
2. Enter a Gemini API Key for **Player 1 (White)** and **Player 2 (Black)**.
3. Choose the models and temperatures for both sides.
4. Click **Start Game** to initialize the battle board.
5. Use **Next Move** to advance one move at a time, or click **Auto Play** for hands-free mode.
6. Watch the **Battle Log** to read the strategic thoughts generated by each model!
